# Images

`sensor-statistics.jpg`, `dynamic-table-settings.jpg` and `precision-comparison.jpg` are genuine screenshots captured from Cortex Code Desktop after executing SQL against synthetic sensor data in Snowflake. They show actual query results and settings, not reconstructed interfaces. SQL query IDs and the local connection label are incidental UI metadata, not credentials.

Charts, when present, are generated from experiment results and are labelled as charts. They are not application screenshots. Product UI and trademarks belong to Snowflake.

`summary-freshness.png` and its SVG compare completed paced runs using the [published measurements](../docs/data/README.md). Rebuild them with [draw_freshness.py](../examples/draw_freshness.py). `main-flow.png` and its SVG are an explanatory architecture diagram, generated by [draw_flow.py](../examples/draw_flow.py).

The four `*-table.png` images and matching SVGs render the article's cost and design comparisons for editors without native tables. Rebuild them with [draw_tables.py](../examples/draw_tables.py). The cost tables read [measured experiment credits](../docs/data/measured-credits.json); they contain no currency conversions or monthly projections. Editable tables and scope are in [the article](../ARTICLE.md) and [credit usage report](../docs/costs.md).
